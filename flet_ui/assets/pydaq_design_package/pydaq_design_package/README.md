# PyDAQ design package

Arquivos criados a partir da tela de referência do PyDAQ.

- `pydaq-interface.svg`: tela completa vetorial e editável.
- `pydaq-components.svg`: biblioteca visual com controles separados.
- `index.html`: protótipo responsivo e navegável.
- `tokens.json`: cores, tipografia, espaçamento, raios e dimensões.

## Importar no Figma ou Penpot

Arraste os arquivos SVG para a prancheta. Os textos, formas, linhas e grupos continuam editáveis. Cada área principal possui um `id`, facilitando localizar sidebar, formulário, gráfico, sinais e controles.

## Abrir o protótipo

Abra `index.html` no navegador. Em telas menores, o menu lateral vira um drawer acionado pelo botão ☰.

## Observação

SVG preserva edição vetorial, mas Auto Layout, variantes e propriedades interativas próprias do Figma precisam ser configurados depois da importação.
